# Image Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an `image()` function to smoltalk for generating images across OpenAI and Google providers. Single round-trip generation only (multi-turn lives in the chat clients).

**Architecture:** Function-based, identical pattern to `embed()`. A top-level `image()` dispatches to per-provider functions via a switch. Reuses `resolveProvider`/`resolveApiKey` from `lib/util/provider.ts`. Existing chat client hierarchy is untouched.

**Tech Stack:** TypeScript, vitest, OpenAI SDK, @google/genai SDK

**Providers in scope:** OpenAI (`gpt-image-1`), Google (`gemini-*-image-*`).
**Out of scope (for now):** Replicate (per-model input schemas — special-case design needed), Modal (no models in registry yet), multi-turn image conversations (belongs in chat clients).

---

## Design Decisions (resolved)

1. **Output normalization**: Always return raw `Uint8Array` bytes + `mimeType`. Users write to file with `fs.writeFile("out.png", img.data)` directly.
2. **Input flexibility**: Accept multiple input types via a tagged `ImageRef` union (bytes / base64 / path / url). A normalization helper converts all forms to `{ data: Uint8Array; mimeType }` before handing off to providers.
3. **Provider-specific knobs**: Use the existing `metadata?: Record<string, unknown>` escape hatch for now. Common knobs (`n`, `size`, `quality`, `outputFormat`) live on `ImageConfig`; per-provider extras go in `metadata`.
4. **Replicate**: Skip — its per-model input schemas need a different design.
5. **Multi-turn / mixed text+image conversation**: Out of scope for `image()`. Use chat clients for that.
6. **Token-based pricing**: `ImageModel` gains `inputImageTokenCost` and `outputImageTokenCost` fields so `gpt-image-1`-style token billing can be modeled accurately. `BaseModel` already provides `inputTokenCost`, `cachedInputTokenCost`, `outputTokenCost`.

```typescript
import { readFile } from "node:fs/promises";
import { extname } from "node:path";

export type ImageRef =
  | { kind: "bytes"; data: Uint8Array; mimeType: string }
  | { kind: "base64"; base64: string; mimeType: string }
  | { kind: "path"; path: string; mimeType?: string }
  | { kind: "url"; url: string; mimeType?: string };

export type NormalizedImage = {
  data: Uint8Array;
  mimeType: string;
};

const EXT_TO_MIME: Record<string, string> = {
  ".png": "image/png",
  ".jpg": "image/jpeg",
  ".jpeg": "image/jpeg",
  ".webp": "image/webp",
  ".gif": "image/gif",
};

export async function normalizeImageRef(ref: ImageRef): Promise<NormalizedImage> {
  switch (ref.kind) {
    case "bytes":
      return { data: ref.data, mimeType: ref.mimeType };
    case "base64":
      return {
        data: new Uint8Array(Buffer.from(ref.base64, "base64")),
        mimeType: ref.mimeType,
      };
    case "path": {
      const buf = await readFile(ref.path);
      const ext = extname(ref.path).toLowerCase();
      const inferred = EXT_TO_MIME[ext] ?? "application/octet-stream";
      return {
        data: new Uint8Array(buf),
        mimeType: ref.mimeType ?? inferred,
      };
    }
    case "url": {
      const res = await fetch(ref.url);
      if (!res.ok) {
        throw new Error(`Failed to fetch image from ${ref.url}: ${res.status}`);
      }
      const buf = new Uint8Array(await res.arrayBuffer());
      const contentType = res.headers.get("content-type") ?? undefined;
      return {
        data: buf,
        mimeType: ref.mimeType ?? contentType ?? "application/octet-stream",
      };
    }
  }
}
```

```typescript
import OpenAI from "openai";
import { toFile } from "openai/uploads";
import { ImageInput, ImageConfig, ImageGenResult, GeneratedImage } from "../image.js";
import { Result, success, failure } from "../types/result.js";
import { getModel, isImageModel } from "../models.js";
import { normalizeImageRef } from "../util/imageRef.js";
import { round } from "../util/util.js";

export async function openaiImage(
  input: ImageInput,
  config: ImageConfig,
  apiKey: string,
): Promise<Result<ImageGenResult>> {
  try {
    const normalized = typeof input === "string" ? { prompt: input } : input;
    const client = new OpenAI({ apiKey });

    const baseParams = {
      model: config.model,
      prompt: normalized.prompt,
      ...(config.n !== undefined ? { n: config.n } : {}),
      ...(config.size !== undefined ? { size: config.size } : {}),
      ...(config.quality !== undefined ? { quality: config.quality } : {}),
      ...(config.outputFormat !== undefined ? { output_format: config.outputFormat } : {}),
      ...(config.background !== undefined ? { background: config.background } : {}),
      ...(config.metadata ?? {}),
    };

    const hasImages = normalized.images && normalized.images.length > 0;
    let response: any;

    if (hasImages) {
      const imageFiles = await Promise.all(
        (normalized.images ?? []).map(async (ref, i) => {
          const n = await normalizeImageRef(ref);
          return toFile(n.data, `image-${i}.${extFromMime(n.mimeType)}`, { type: n.mimeType });
        }),
      );
      const maskFile = normalized.mask
        ? await (async () => {
            const m = await normalizeImageRef(normalized.mask!);
            return toFile(m.data, `mask.${extFromMime(m.mimeType)}`, { type: m.mimeType });
          })()
        : undefined;

      response = await client.images.edit({
        ...baseParams,
        image: imageFiles.length === 1 ? imageFiles[0] : imageFiles,
        ...(maskFile ? { mask: maskFile } : {}),
      });
    } else {
      response = await client.images.generate(baseParams);
    }

    const mimeType = mimeFromFormat(config.outputFormat) ?? "image/png";
    const images: GeneratedImage[] = (response.data ?? []).map((d: any) => ({
      data: new Uint8Array(Buffer.from(d.b64_json, "base64")),
      mimeType,
      revisedPrompt: d.revised_prompt,
    }));

    const tokenUsage = extractUsage(response);
    const costEstimate = tokenUsage
      ? calculateImageCost(config.model, tokenUsage, images.length)
      : calculatePerImageCost(config.model, images.length);

    return success({
      images,
      model: config.model,
      tokenUsage,
      costEstimate,
    });
  } catch (err) {
    return failure(
      err instanceof Error ? err.message : "OpenAI image request failed",
    );
  }
}

function extFromMime(mime: string): string {
  if (mime === "image/jpeg") return "jpg";
  if (mime === "image/webp") return "webp";
  return "png";
}

function mimeFromFormat(fmt?: string): string | undefined {
  if (!fmt) return undefined;
  if (fmt === "jpeg") return "image/jpeg";
  if (fmt === "webp") return "image/webp";
  return "image/png";
}

function extractUsage(response: any) {
  const u = response?.usage;
  if (!u) return undefined;
  return {
    inputTokens: u.input_tokens ?? 0,
    outputTokens: u.output_tokens ?? 0,
    cachedInputTokens: u.input_tokens_details?.cached_tokens,
    totalTokens: u.total_tokens,
  };
}

function calculateImageCost(modelName: string, usage: any, _imageCount: number) {
  const model = getModel(modelName);
  if (!model || !isImageModel(model)) return undefined;

  const textIn = (usage.inputTokens ?? 0) - (usage.cachedInputTokens ?? 0);
  const cachedIn = usage.cachedInputTokens ?? 0;
  const imgOut = usage.outputTokens ?? 0;

  const inputCost = round(
    (textIn * (model.inputTokenCost ?? 0)) / 1_000_000,
    6,
  );
  const cachedCost = round(
    (cachedIn * (model.cachedInputTokenCost ?? 0)) / 1_000_000,
    6,
  );
  const outputCost = round(
    (imgOut * (model.outputImageTokenCost ?? 0)) / 1_000_000,
    6,
  );
  const totalCost = round(inputCost + cachedCost + outputCost, 6);
  return {
    inputCost,
    outputCost,
    cachedInputCost: cachedCost,
    totalCost,
    currency: "USD",
  };
}

function calculatePerImageCost(modelName: string, imageCount: number) {
  const model = getModel(modelName);
  if (!model || !isImageModel(model) || !model.costPerImage) return undefined;
  const totalCost = round(model.costPerImage * imageCount, 6);
  return { inputCost: 0, outputCost: totalCost, totalCost, currency: "USD" };
}
```

### Task 5: Implement Google Image Provider

Google's image generation goes through `client.models.generateContent({ model, contents, config })` with `responseModalities: ["IMAGE"]` (or `["IMAGE", "TEXT"]`). Returns `candidates[0].content.parts[]` where image parts have `inlineData: { mimeType, data: <base64> }`.

`contents` accepts a string OR a structured Content with parts (text + inlineData parts for reference images).

Note: Gemini does not natively support `n` for image gen — it returns however many images its response contains (typically 1 per call). We pass single calls only and ignore `n` for Gemini, or document that the user should call multiple times.

```typescript
import { GoogleGenAI } from "@google/genai";
import { ImageInput, ImageConfig, ImageGenResult, GeneratedImage } from "../image.js";
import { Result, success, failure } from "../types/result.js";
import { getModel, isImageModel } from "../models.js";
import { normalizeImageRef } from "../util/imageRef.js";
import { round } from "../util/util.js";

export async function googleImage(
  input: ImageInput,
  config: ImageConfig,
  apiKey: string,
): Promise<Result<ImageGenResult>> {
  try {
    const normalized = typeof input === "string" ? { prompt: input } : input;
    const client = new GoogleGenAI({ apiKey });

    const parts: any[] = [{ text: normalized.prompt }];
    if (normalized.images) {
      for (const ref of normalized.images) {
        const img = await normalizeImageRef(ref);
        parts.push({
          inlineData: {
            mimeType: img.mimeType,
            data: Buffer.from(img.data).toString("base64"),
          },
        });
      }
    }

    const response = await client.models.generateContent({
      model: config.model,
      contents: [{ role: "user", parts }],
      config: {
        responseModalities: ["IMAGE", "TEXT"],
        ...(config.metadata ?? {}),
      },
    });

    const images: GeneratedImage[] = [];
    const candidateParts = response.candidates?.[0]?.content?.parts ?? [];
    for (const part of candidateParts) {
      if (part.inlineData?.data && part.inlineData?.mimeType) {
        images.push({
          data: new Uint8Array(Buffer.from(part.inlineData.data, "base64")),
          mimeType: part.inlineData.mimeType,
        });
      }
    }

    return success({
      images,
      model: config.model,
      costEstimate: calculateGoogleImageCost(config.model, images.length),
      // Gemini image gen doesn't reliably return token usage in a useful form here
    });
  } catch (err) {
    return failure(
      err instanceof Error ? err.message : "Google image request failed",
    );
  }
}

function calculateGoogleImageCost(modelName: string, imageCount: number) {
  const model = getModel(modelName);
  if (!model || !isImageModel(model) || !model.costPerImage) return undefined;
  const totalCost = round(model.costPerImage * imageCount, 6);
  return { inputCost: 0, outputCost: totalCost, totalCost, currency: "USD" };
}
```

```typescript
import { resolveProvider, resolveApiKey } from "./util/provider.js";
import { failure } from "./types/result.js";
import { openaiImage } from "./image/openai.js";
import { googleImage } from "./image/google.js";

// ... existing types above ...

export async function image(
  input: ImageInput,
  config: ImageConfig,
): Promise<Result<ImageGenResult>> {
  let provider: string;
  try {
    provider = resolveProvider(config.model, config.provider);
  } catch (err) {
    return failure(
      err instanceof Error ? err.message : "Failed to resolve provider",
    );
  }

  const apiKey = resolveApiKey(provider, config);

  switch (provider) {
    case "openai":
    case "openai-responses": {
      if (!apiKey) {
        return failure(
          "No OpenAI API key provided. Set openAiApiKey in config or the OPENAI_API_KEY environment variable.",
        );
      }
      return openaiImage(input, config, apiKey);
    }
    case "google": {
      if (!apiKey) {
        return failure(
          "No Google API key provided. Set googleApiKey in config or the GEMINI_API_KEY environment variable.",
        );
      }
      return googleImage(input, config, apiKey);
    }
    default:
      return failure(
        `Provider "${provider}" does not support image generation`,
      );
  }
}
```

## Notes / Open Questions

1. **`gpt-image-1` token pricing accuracy** — Verify current numbers against the OpenAI pricing page at implementation time. Pricing changes occasionally.
2. **Response shape variance** — `client.images.generate` and `client.images.edit` may differ slightly in usage reporting. Tests use `any` casts; verify against live API.
3. **Gemini `n` parameter** — Currently ignored for Gemini. If users need multiple images, document that they should call `image()` multiple times. A future enhancement could parallelize this internally.
4. **Streaming image generation** — OpenAI now supports streaming partial images. Out of scope for v1; would require changing the return type to an `AsyncGenerator`. Can be added later as `imageStream()` mirroring `textStream()`.
5. **Multi-turn image conversations** — Out of scope for `image()`. Belongs in chat clients. The chat clients already accept image *inputs* via message classes; supporting image *outputs* (assistant returning images) would require extending `AssistantMessage` and the streaming/sync paths in each chat client. That's a separate, larger project.
6. **`UserMessage` already supports images** — When that work happens, `normalizeImageRef` should be reusable.
